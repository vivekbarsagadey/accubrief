# API Documentation - AccuBrief v1.0

## Overview

AccuBrief provides a RESTful API for managing video sessions, recordings, summaries, and digital signature verification. All API endpoints are versioned under `/v1/`.

**Base URL:** `https://api.accubrief.com/v1`

## Authentication

### API Key Authentication

All API requests require authentication using an API key provided in the `X-API-Key` header.

```http
X-API-Key: your-api-key-here
```

### Widget Token Authentication

Widget users authenticate using JWT tokens passed as URL parameters. These tokens are generated by the backend and have a 15-minute expiry.

```
https://widget.accubrief.com/{sessionId}?role=host&token={jwt}
```

## Common Response Codes

| Code | Description |
|------|-------------|
| 200 | Success |
| 201 | Created |
| 400 | Bad Request - Malformed request |
| 401 | Unauthorized - Invalid or missing API key |
| 403 | Forbidden - Insufficient permissions |
| 404 | Not Found - Resource doesn't exist |
| 422 | Unprocessable Entity - Validation error |
| 429 | Too Many Requests - Rate limit exceeded |
| 500 | Internal Server Error |

## Error Response Format

```json
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message",
    "details": {}
  }
}
```

## Sessions API

### Create Session

Creates a new video session between host and client participants.

**Endpoint:** `POST /v1/sessions`

**Request Headers:**
```http
Content-Type: application/json
X-API-Key: your-api-key
```

**Request Body:**
```json
{
  "host": {
    "name": "John Doe",
    "externalUserId": "user_123"
  },
  "client": {
    "name": "Jane Smith",
    "externalUserId": "client_456"
  },
  "autoStartRecording": true,
  "webhookUrl": "https://your-app.com/webhooks/accubrief"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `host` | object | Yes | Host participant information |
| `host.name` | string | Yes | Display name (1-100 chars) |
| `host.externalUserId` | string | No | Your system's user ID |
| `client` | object | Yes | Client participant information |
| `client.name` | string | Yes | Display name (1-100 chars) |
| `client.externalUserId` | string | No | Your system's user ID |
| `autoStartRecording` | boolean | No | Auto-start recording (default: true) |
| `webhookUrl` | string | No | URL to receive event webhooks |

**Response:** `201 Created`
```json
{
  "sessionId": "sess_abc123def456",
  "widgetUrls": {
    "host": "https://widget.accubrief.com/sess_abc123def456?role=host&token=eyJ...",
    "client": "https://widget.accubrief.com/sess_abc123def456?role=client&token=eyJ..."
  },
  "createdAt": "2025-12-07T10:30:00Z"
}
```

**Example:**
```bash
curl -X POST "https://api.accubrief.com/v1/sessions" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{
    "host": {"name": "Dr. Smith"},
    "client": {"name": "Patient Jones"},
    "autoStartRecording": true
  }'
```

### Get Session

Retrieves session details by ID.

**Endpoint:** `GET /v1/sessions/{sessionId}`

**Request Headers:**
```http
X-API-Key: your-api-key
```

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `sessionId` | string | Session identifier |

**Response:** `200 OK`
```json
{
  "sessionId": "sess_abc123def456",
  "status": "completed",
  "createdAt": "2025-12-07T10:30:00Z",
  "startedAt": "2025-12-07T10:31:00Z",
  "endedAt": "2025-12-07T11:00:00Z",
  "participants": [
    {
      "name": "Dr. Smith",
      "role": "host"
    },
    {
      "name": "Patient Jones",
      "role": "client"
    }
  ],
  "summaryId": "sum_xyz789"
}
```

**Session Status Values:**

| Status | Description |
|--------|-------------|
| `scheduled` | Session created, not started |
| `active` | Session in progress |
| `ended` | Session ended, processing pending |
| `processing` | Summary being generated |
| `completed` | Summary ready |
| `failed` | Processing failed |

## Signatures API

### Verify Signature

Verifies the digital signature of a summary document.

**Endpoint:** `POST /v1/signatures/verify`

**Request Headers:**
```http
Content-Type: application/json
X-API-Key: your-api-key  (optional for public verification)
```

#### Option 1: Verify by Summary ID

**Request Body:**
```json
{
  "summaryId": "sum_xyz789"
}
```

#### Option 2: Verify by Document

**Request Body:**
```json
{
  "document": "eyJjb252ZXJzYXRpb25PdmVydmlldyI6...",
  "signatureValue": "SGVsbG8gV29ybGQ...",
  "publicKeyId": "accubrief-main-key-1"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `document` | string | Base64-encoded JSON document |
| `signatureValue` | string | Base64-encoded signature |
| `publicKeyId` | string | ID of public key to use |

**Response:** `200 OK`
```json
{
  "isValid": true,
  "reason": null,
  "summaryId": "sum_xyz789",
  "documentHash": "SHA256:a1b2c3d4e5f6...",
  "verifiedAt": "2025-12-07T12:00:00Z"
}
```

**Verification Failure Response:**
```json
{
  "isValid": false,
  "reason": "Document hash mismatch - content may have been tampered",
  "summaryId": "sum_xyz789",
  "documentHash": "SHA256:x1y2z3..."
}
```

## Webhooks

AccuBrief sends webhook notifications for key events. Webhooks are sent as HTTP POST requests to the URL specified during session creation.

### Webhook Security

All webhooks include an HMAC signature in the `X-AccuBrief-Signature` header:

```http
X-AccuBrief-Signature: sha256=abc123def456...
```

**Verification:**
```python
import hmac
import hashlib

def verify_webhook(body: bytes, signature: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(
        secret.encode(),
        body,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(signature, expected)
```

### Webhook Events

#### session.started

Sent when a session becomes active (both participants joined).

```json
{
  "event": "session.started",
  "timestamp": "2025-12-07T10:31:00Z",
  "data": {
    "sessionId": "sess_abc123def456",
    "startedAt": "2025-12-07T10:31:00Z"
  }
}
```

#### session.ended

Sent when a session is terminated.

```json
{
  "event": "session.ended",
  "timestamp": "2025-12-07T11:00:00Z",
  "data": {
    "sessionId": "sess_abc123def456",
    "endedAt": "2025-12-07T11:00:00Z",
    "durationSeconds": 1740
  }
}
```

#### summary.ready

Sent when a summary is generated and signed.

```json
{
  "event": "summary.ready",
  "timestamp": "2025-12-07T11:01:00Z",
  "data": {
    "sessionId": "sess_abc123def456",
    "summaryId": "sum_xyz789",
    "generatedAt": "2025-12-07T11:01:00Z"
  }
}
```

#### summary.failed

Sent when summary generation fails.

```json
{
  "event": "summary.failed",
  "timestamp": "2025-12-07T11:01:00Z",
  "data": {
    "sessionId": "sess_abc123def456",
    "error": "Transcription failed: No audio content detected",
    "errorCode": "TRANSCRIPTION_FAILED"
  }
}
```

### Webhook Retry Policy

Failed webhook deliveries are retried with exponential backoff:

| Attempt | Delay |
|---------|-------|
| 1 | Immediate |
| 2 | 1 minute |
| 3 | 5 minutes |
| 4 | 30 minutes |
| 5 | 2 hours |

Webhooks are considered failed if:
- Response status is not 2xx
- Connection timeout (10 seconds)
- No response within 30 seconds

## WebSocket Signaling API

The signaling server handles WebRTC connection establishment.

**Endpoint:** `wss://api.accubrief.com/v1/signaling/{sessionId}`

**Query Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `token` | string | JWT join token |

### Message Format

All messages are JSON objects with a `type` field:

```json
{
  "type": "message-type",
  "payload": {}
}
```

### Client → Server Messages

#### offer

Send SDP offer to remote peer.

```json
{
  "type": "offer",
  "payload": {
    "sdp": "v=0\r\no=- 123456 2 IN IP4 127.0.0.1\r\n..."
  }
}
```

#### answer

Send SDP answer to remote peer.

```json
{
  "type": "answer",
  "payload": {
    "sdp": "v=0\r\no=- 789012 2 IN IP4 127.0.0.1\r\n..."
  }
}
```

#### ice-candidate

Send ICE candidate to remote peer.

```json
{
  "type": "ice-candidate",
  "payload": {
    "candidate": "candidate:842163049 1 udp 1677729535 ...",
    "sdpMid": "0",
    "sdpMLineIndex": 0
  }
}
```

### Server → Client Messages

#### offer

Received SDP offer from remote peer.

```json
{
  "type": "offer",
  "payload": {
    "sdp": "v=0\r\no=- 123456 2 IN IP4 127.0.0.1\r\n..."
  }
}
```

#### answer

Received SDP answer from remote peer.

```json
{
  "type": "answer",
  "payload": {
    "sdp": "v=0\r\no=- 789012 2 IN IP4 127.0.0.1\r\n..."
  }
}
```

#### ice-candidate

Received ICE candidate from remote peer.

```json
{
  "type": "ice-candidate",
  "payload": {
    "candidate": "candidate:842163049 1 udp 1677729535 ...",
    "sdpMid": "0",
    "sdpMLineIndex": 0
  }
}
```

#### peer-joined

Remote peer has joined the session.

```json
{
  "type": "peer-joined",
  "payload": {
    "role": "client",
    "name": "Patient Jones"
  }
}
```

#### peer-left

Remote peer has left the session.

```json
{
  "type": "peer-left",
  "payload": {
    "role": "client",
    "reason": "disconnected"
  }
}
```

#### error

Error occurred during signaling.

```json
{
  "type": "error",
  "payload": {
    "code": "INVALID_TOKEN",
    "message": "Token has expired"
  }
}
```

## SDK Examples

### Python

```python
import requests

class AccuBriefClient:
    def __init__(self, api_key: str, base_url: str = "https://api.accubrief.com/v1"):
        self.api_key = api_key
        self.base_url = base_url
        self.headers = {"X-API-Key": api_key}
    
    def create_session(self, host_name: str, client_name: str, **kwargs) -> dict:
        response = requests.post(
            f"{self.base_url}/sessions",
            headers=self.headers,
            json={
                "host": {"name": host_name},
                "client": {"name": client_name},
                **kwargs
            }
        )
        response.raise_for_status()
        return response.json()
    
    def get_summary(self, summary_id: str) -> dict:
        response = requests.get(
            f"{self.base_url}/summaries/{summary_id}",
            headers=self.headers
        )
        response.raise_for_status()
        return response.json()
    
    def verify_signature(self, summary_id: str) -> dict:
        response = requests.post(
            f"{self.base_url}/signatures/verify",
            headers=self.headers,
            json={"summaryId": summary_id}
        )
        response.raise_for_status()
        return response.json()

# Usage
client = AccuBriefClient("your-api-key")
session = client.create_session("Dr. Smith", "Patient Jones")
print(f"Host URL: {session['widgetUrls']['host']}")
```

### JavaScript/Node.js

```javascript
class AccuBriefClient {
  constructor(apiKey, baseUrl = 'https://api.accubrief.com/v1') {
    this.apiKey = apiKey;
    this.baseUrl = baseUrl;
  }

  async request(method, path, body = null) {
    const response = await fetch(`${this.baseUrl}${path}`, {
      method,
      headers: {
        'X-API-Key': this.apiKey,
        'Content-Type': 'application/json',
      },
      body: body ? JSON.stringify(body) : null,
    });
    
    if (!response.ok) {
      throw new Error(`API Error: ${response.status}`);
    }
    
    return response.json();
  }

  createSession(hostName, clientName, options = {}) {
    return this.request('POST', '/sessions', {
      host: { name: hostName },
      client: { name: clientName },
      ...options,
    });
  }

  getSummary(summaryId) {
    return this.request('GET', `/summaries/${summaryId}`);
  }

  verifySignature(summaryId) {
    return this.request('POST', '/signatures/verify', { summaryId });
  }
}

// Usage
const client = new AccuBriefClient('your-api-key');
const session = await client.createSession('Dr. Smith', 'Patient Jones');
console.log(`Host URL: ${session.widgetUrls.host}`);
```
